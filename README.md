# OpenTab
Know the bill before you get the bill. Compare real, legally published hospital prices in the SF Bay Area by voice.

- `web/` – Next.js app (App Router, TypeScript, Tailwind) + Convex backend
- `actor/` – Apify Actor that parses hospital price transparency files
- `elastic/` – Elastic index setup, ingest, and Agent Builder tools
- `docs/` – setup and demo docs

Setup: see [docs/SETUP.md](docs/SETUP.md). Full README comes in milestone 9.
